# Chat with your docs

Project scaffold for a document-chat application with a FastAPI backend and a Streamlit frontend.

## Project structure

- `backend/` - API application, configuration, and document-processing services
- `frontend/` - Streamlit application
- `data/` - local documents; contents are ignored by Git
- `tests/` - automated tests
- `.env.example` - placeholder for documenting required environment variables

Copy `.env.example` to `.env` and add configuration values as the application requires them. Keep credentials and private documents out of version control.
